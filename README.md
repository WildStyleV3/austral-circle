# Círculo Austral

**A website for interdisciplinary strategic thinking in Chile.**

Pages on strategic thinking, space and longevity, alongside interviews and opinion articles.

[Visit the website](https://austral-circle.vercel.app)

## Built with

Next.js 14 · React 18 · TypeScript · Markdown content

## Run locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Build the site |
| `npm start` | Serve the production build |
| `npm run lint` | Run the configured lint check |

## Structure

| Path | Purpose |
| --- | --- |
| `src/app/` | Pages, routes and global styles |
| `src/components/` | Shared navigation and visual components |
| `src/lib/` | Content loading helpers |
| `content/entrevistas/` | Interviews in Markdown |
| `content/opinion/` | Opinion articles in Markdown |

The repository also contains the Aeterna page under `src/app/aeterna/`.
